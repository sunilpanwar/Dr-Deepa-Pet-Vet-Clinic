📄 Google Drive JSON Reader

Read JSON content from Google Drive without downloading

📋 How to Use:

  1. Make sure your Google Drive file is set to "Anyone with the link can view"
  2. Extract the File ID from your Google Drive link
  3. Paste the File ID below (or use the pre-filled one)
  4. Click "Load JSON Data"

Example: From https://drive.google.com/file/d/FILE_ID/view, copy the FILE_ID
