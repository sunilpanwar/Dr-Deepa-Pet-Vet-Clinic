This folder is for storing all website images. The website uses fallback images from Unsplash, but you can replace them with your own images.

## Image Guidelines

- **Format**: JPG or PNG
- **Optimization**: Compress images for web to improve loading speed
- **Alt Text**: Already included in HTML for accessibility
- **Fallback**: The website uses Unsplash images as fallbacks if local images are not found

## Tools for Image Optimization

- [TinyPNG](https://tinypng.com/) - Compress PNG and JPG images
- [Squoosh](https://squoosh.app/) - Advanced image compression
- [ImageOptim](https://imageoptim.com/) - Mac app for image optimization

## Note

The website will work perfectly with the fallback images from Unsplash. Replace them with actual clinic photos when available for a more personalized experience.
